# Fonts

Bundled so the board works offline on a LAN (no CDN). All three are under the SIL Open Font
License, reproduced beside each file.

| File | Family | Weight | Licence |
|---|---|---|---|
| `oswald.woff2` | Oswald — the condensed grotesk of airport boards | 600 | `OFL-Oswald.txt` |
| `jetbrains-mono.woff2` | JetBrains Mono | 700 | `OFL-JetBrainsMono.txt` |
| `nunito.woff2` | Nunito — rounded | 800 | `OFL-Nunito.txt` |

Latin subsets as served by Google Fonts. A theme picks one with `--flap-font`.
