Integrate

Settings · Board · API docs · llms.txt

Everything the settings page does, the API does. We do not build a calendar panel or a chat bot into the board; you point your own script, automation or agent at these lines. Each is pre-filled with this host and this install's token.

The host is what another machine uses to reach this board — on a LAN usually http://<this machine's IP>:8080. Edit it if the lines will run elsewhere. Every copied line carries your token: it is a secret, keep it out of shared documents.

Put something on the board now

The shortest call. Live immediately, above everything else. JSON or plain text.

Show it for a while

A window. Either end may be left out. Times are ISO-8601 with your offset.

Every day at a time

A window that ends before it starts crosses midnight (22:00 → 06:00).

On certain weekdays

repeat_days is a sum: Mon 1 · Tue 2 · Wed 4 · Thu 8 · Fri 16 · Sat 32 · Sun 64. Weekdays = 31.

A picture on the board

Upload once, then use the token the response gives you. Size it on the Images panel, or inline with @WxH.

A QR code on the board

Two calls: the server draws the code as a picture, then it goes in a message. Drawn whole over its block, so a phone reads it.

What is live, and clearing it

The display

Preset, animation, sound, theme, idle text. The TV picks it up on its next poll.

What the TV sees

Public, no token. Poll it with If-None-Match and you get 304 until something changes.
