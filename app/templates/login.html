Where the token is

Run the line for how this board is running, in a terminal on the machine that runs it. Add | pbcopy on a Mac or | xclip -selection clipboard on Linux to put it straight on the clipboard instead of on the screen.

The container · docker compose up

$ docker compose exec departureboard cat /data/api_token

A server started from the checkout · uv run

$ cat data/api_token

Or the first-boot log, where it was printed once

$ docker compose logs departureboard | grep -A 1 "API token"

A token from one server does not open another: a uv run server keeps its own under data/, the container keeps its own in the data volume.
