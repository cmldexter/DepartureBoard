# Integrations

The board has an API; the integrations are yours. This folder will hold:

- `curl/examples.sh` — runnable examples for every task the `/integrate` page shows
- `skills/departureboard/SKILL.md` — an Agent Skill so a coding or chat agent can post and schedule
- `hermes/` — an example tool definition for a Hermes agent

They arrive with the integrate page. Until then, `/docs` on your running board is the reference.
